🔥 Cấu hình Firebase

Thay thế đoạn code bên dưới vào cuối file HTML này để kết nối với Firebase project của bạn.

// Thay thế config này
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project-id",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123:web:abc123"
};
🔗 Deep Link Schema

Trong AndroidManifest.xml và Info.plist của MAUI app, đăng ký scheme sau:

vinh-khanh://poi/{poiId}?lang={vi|en|ja}
